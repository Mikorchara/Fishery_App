# 网页使用指南

首次配置看 [部署指南](DEPLOYMENT.md)，启动/停止看 [日常入口](../BUILD_RUN.md)。本页只说明使用，不重复部署命令。

## 首页与水质

首页显示连接、三项水质、当前异常概况、趋势和AI入口。水质监测页提供详细值、质量与历史。源标SIMULATOR就代表模拟数据；LOCAL VIDEO只表示录制素材。

必须同时看观测时间、质量、新鲜度和上报状态。缺测不是0；过期/离线读数是留存数据，不是现在重新采样。“当前未见异常信号”也不代表专业健康保证。

历史5/10/30/60分钟按已存储窗口统计，不是连续实时采样；缺口不补线，不以历史推断当前正常。图表细节见 [历史趋势](../deep-dive/HISTORY_CHART_UI.md)。

## AI智能助手

选择模型、设备和Normal/Streaming，再提问。发送前核对冻结的配置、工具权限及联网确认。启动、切模式和保存Tool选择不自动调用模型；“测试连接”与“发送”可能计费。

| 工具 | 使用范围 |
|---|---|
| 当前水质 | 本轮授权设备的Monitoring事实 |
| 项目养殖知识 | 当前启用知识中的检索证据，不是现场事实 |
| 历史水质 | 授权时间范围的有界统计，不伪造当前观测 |
| 水质实验评分 | 需独立启动开关、Policy和Scope；非专业标准 |

在“系统设置 → Assistant Tool授权”保存选择。服务器未启用Assistant或相应试用时，勾选不会自行补上权限；按部署指南用正确入口启动。

评分基于本窗口规则，缺测/无效/过期/离线不给总分。100分只代表已评估规则没有异常，不代表鱼群健康、无疾病、长期稳定或适养。[评分说明](../deep-dive/EXPERIMENTAL_WATER_SCORE.md)

Stop会发起取消，不等于远端模型一定停止收费。失败、超时和断流不自动重试或切Provider；只有通过Source/Commit的完整答复进入成功历史。QQ有独立预算和权限，Web勾选Tool不会扩大QQ能力。

## 视频监控

用带视频入口加载根目录sample.mp4；支持暂停、拖动、循环与全屏。中间看画面，两侧看水质与视觉数据；可分别收起或“专注视频”。画面与数据时间独立，不因为录像里有鱼就生成检测结果。真实视频流/NPU尚待独立对接。

## 事件记录

一个可靠风险周期显示一行，等级变化、原始ID、证据、ACK和人工操作在详情中。已恢复摘要显示历史最高等级、首次和恢复时间，历史值标“异常时读数”。

| 显示 | 代表什么 |
|---|---|
| 异常中 | 当前有有效异常证据，包含恢复观察过程 |
| 状态待核实 | 缺测/过期/离线或旧证据不足，不能判断恢复 |
| 已恢复 | 可靠观测满足规则消退条件，不代表疾病治愈 |
| 已人工结束 | 操作者结束旧提醒，监测原状态与证据仍保留 |
| 已确认 / 未确认 | 只表示人员是否知晓本周期当前等级；升级后需重新确认 |

“确认已知晓”不解决异常、不停止规则；符合条件的失联风险才可人工结束。可靠异常不能被人工结束掩盖，新HIT会重新提醒。

“删除已结束周期”会永久删除整个周期及明确告知的ACK历史，应用内不可撤销；确认框列出数量，一次确认，不用对同一周期删两遍。活动、恢复观察和待核实不能删；人工结束留痕继续保护。旧记录没有可靠归族时独立显示，不凭名称合并。

筛选时间、关键词、等级和状态可组合；“清理全部已结束事件”不受当前筛选影响，需两步确认，且不隐式删受保护ACK或人工留痕。详情规则见 [事件管理](../deep-dive/EVENT_MANAGEMENT.md)。

## 知识与设置

知识库可新增/编辑、停用、删除与恢复，并按当前启用或全部导出JSON/Markdown。导出不是完整数据库备份，目前没有通用回导入。编辑的内容会影响后续检索，但不会写回Prototype。

系统设置保存当前实例的模型/设备偏好、执行预算、Tool授权及RAG参数。API Key由当前电脑操作者在私有Store配置，不放在Git、JSON或浏览器存储中。路径或Windows用户变化后不能假设旧Key仍有效。

## 故障时先看什么

1. 确认启动的是Management、使用预期实例，并且端口没有旧服务。
2. Check只证明离线配置，不证明密钥、网络或平台权限有效。
3. QQ的AI_ADMITTED只是准入，继续查看AI_TASK_FINISHED及错误码；平台接受与客户端显示分开确认。
4. 删除冲突时刷新后重新预览，不自动重试；缺库、旧Schema不靠重新初始化“修复”。

日志和恢复见 [维护说明](../deep-dive/OPERATIONS.md)。不要贴密钥、完整OpenID、聊天正文或数据库到公开群求助。
