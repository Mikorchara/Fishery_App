# 首次初始化背景资料

`eel_knowledge_v1.json` 是本项目原有 Git 跟踪鳗鲡知识文本的固定副本，
不包含任何用户数据库、监测记录或密钥。SHA-256：
`6aa00314094b3660bb3ef62bf856976c9e7cfb85ead88a7a8f4c388a636c012e`。

首次显式初始化时，程序将其转换为新实例中的31条可编辑背景资料。
正常启动只读写实例自己的 `knowledge.sqlite3`，不重新导入、不覆盖编辑。
`tests/fixtures` 的冻结副本仍仅供原有测试和历史基线使用。

这些文本是项目初始参考资料，**不是经过专业审核的养殖标准、疾病诊断或用药依据**。
来源文件未附完整书目；维护者应继续核对、补充来源并修订内容。
知识资料不能证明当前鱼塘状态，现场数据仍以本轮授权 Monitoring 查询为准。

## 溶解氧与摄食资料

新版种子文件 eel_oxygen_feeding_v1.json 收录六条经原始论文核对的背景资料，统一标注日本鳗鲡（Anguilla japonica）。每条保留出处、发表年份、实验条件和原文定位。资料描述实验结果，现场摄食应根据实际观察判断。

- 1983 年的研究提供 mg/L 测点、相对摄食率趋势，以及不同于摄食的生长和饲料效率结论。表 1 的 2.11、2.94 和 3.60 mg/L 只登记为实测点。约 4.0 mg/L 和约 4.5 mg/L 分别描述实验中的近似摄食和生长相关变化。[原始论文](https://doi.org/10.2331/suisan.49.1335)
- 1986 年的研究提供恒定溶氧和昼夜波动下的观察。原文使用空气饱和度百分比，各条只登记该实验口径。[原始论文](https://doi.org/10.2331/suisan.52.597)

第一版以明确来源的实测点和趋势替代旧资料中「1–3 mg/L 必然停食」「3–5 mg/L 统一减少摄食」的区间断言。旧的通用正常或致死线、固定处置建议，以及其它主题的无来源数值和病害用药条目留作历史参考，等待独立核对。原种子保留用于既有实例和历史对照，新资料为单独资源。
